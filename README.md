# АРКА 123

Сайт пространства для мастер-классов и встреч в Минске. Проект построен на React, TypeScript и Vite.

## Локальный запуск

Требуются Node.js и pnpm.

```sh
pnpm install
pnpm dev
```

## Production-сборка

```sh
pnpm build
pnpm preview
```

Готовая статическая сборка создаётся в `dist/`.

## Медиафайлы

В репозитории хранится 3D-модель, используемая приложением. Альтернативные версии моделей и неиспользуемое видео исключены через `.gitignore`; локальные файлы при этом не удаляются.
